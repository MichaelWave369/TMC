# Contributing to Total Memory Core

Thanks for considering a contribution. TMC is MIT-licensed, and proposals
through GitHub issues and pull requests are welcome.

## Before submitting
- Open an issue for substantial changes and discuss scope first.
- Keep changes focused, include tests, and clearly distinguish simulation
  and mock results from real-world verified evidence.
- Do not include personal memories, credentials, live databases, private logs,
  confidential test fixtures, or generated support bundles.
- Do not change governance or permission boundaries merely to make a test pass.
- Contributors are responsible for ensuring they may license their submitted
  changes under MIT. Retain required third-party attribution and licenses.

## Review and release
All PRs require maintainer review. A green CI check is not permission to merge,
publish, deploy, or access data. Maintainers may request changes or decline
submissions. See [SECURITY.md](SECURITY.md) for responsible disclosures.

## Security reports
Please use private vulnerability reporting where enabled. Do not post working
exploits or real secrets in public issues.
